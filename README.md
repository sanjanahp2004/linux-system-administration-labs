# Linux System Administration & Troubleshooting Labs

A practical learning repository documenting my Linux knowledge, command-line practice, system administration exercises, and troubleshooting activities.

## About This Repository

This repository is part of my journey toward becoming a DevOps Engineer. It organizes Linux concepts and practical exercises into structured, easy-to-follow documentation.

The focus is on understanding Linux commands, managing system resources, administering services, and developing a systematic approach to troubleshooting.

## Topics Covered

### 1. Linux Fundamentals
- Linux Introduction
- Linux File System
- Navigation Commands

### 2. File Management and Text Processing
- File Operations
- Searching Files
- Text Processing Commands
- Vi Editor
- Input/Output Redirection and Pipes

### 3. Users and Permissions
- User and Group Management
- File Permissions

### 4. Processes, Services, and Logs
- Process Management
- Services with systemctl
- Log Management and Analysis

### 5. Storage and Package Management
- File Compression
- Disk Management
- Package Management

### 6. Networking and Remote Access
- Linux Networking
- SSH (Secure Shell)

### 7. Shell and Automation
- Shell Scripting
- Environment Variables
- Cron Jobs

## Practical Learning Approach

For each documented lab, I aim to include:
- Objective and use case
- Commands and explanations
- Practical steps
- Expected output and verification
- Troubleshooting notes
- Screenshots where useful

## Environment

- Linux: Amazon Linux 2023 for applicable hands-on exercises
- Platform: AWS EC2 for applicable server administration labs
- Version control: Git and GitHub
